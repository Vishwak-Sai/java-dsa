# Java Exception Handling Examples

Each file demonstrates one concept and has its own `main` method.

## Concepts included

1. Basic `try` / `catch`
2. Multiple catch blocks
3. `finally`
4. `throw`
5. `throws`
6. Custom exceptions
7. Try-with-resources
8. Multi-catch
9. Catch-block order
10. Nested try/catch
11. Exception propagation
12. Exception chaining
13. Checked vs. unchecked exceptions

## Run an example

Compile all files from this folder:

```powershell
javac *.java
```

Then run one class, for example:

```powershell
java BasicTryCatch
```

`ThrowKeyword.java` intentionally terminates with an exception to demonstrate `throw`.
